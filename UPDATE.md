# How this skill evolves

Stolen from Distilly's merger, not its persona pipeline.

## When new tweets land

1. Snapshot the current `SKILL.md` + `methodology.md` into `versions/vN/` (copy, do not move).
2. Pull only Loki-authored posts. Replies from other people are not doctrine.
3. Bottom-up the five dimensions again *for the delta only*. Hammer every new line to an id.
4. **Append. Do not overwrite an old conclusion.** If the new tweet contradicts an old law, keep both and add a tension note in methodology §6. Distilly's rule: never silently replace a prior conclusion.
5. Upgrade `meta.json` (`version`, `updated_at`, `corpus.last_add_id`, counts).
6. Log the delta in `CHANGELOG.md`.

## What never gets imported just because Distilly / a deck / a blog has it

Day 0, three reversals, SSG/CSR tables, Schema-as-annotation, FO 5-step, CRO frameworks, “pages are not the unit” as a slogan. Blind-spot checklist only. No tweet id → do not add.

## Priority of source material (Distilly's ranking, we keep)

Long-form writing **by him** > **decision / refusal replies** > thanks-only / empty RTs. We already drop conversation-partner tweets in the dump.
