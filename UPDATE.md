# How this skill evolves

## When new tweets land

1. Take only Loki-authored posts. Replies from other people are not doctrine.
2. Bottom-up the five dimensions again *for the delta only*. Hammer every new line to an id.
3. **Append. Do not overwrite an old conclusion.** If the new tweet contradicts an old law, keep both and add a tension note in methodology §6.
4. Update `meta.json` (`version`, `updated_at`, `corpus.last_add_id`, counts).
5. Log the delta in `CHANGELOG.md`.

## What never gets imported

Day 0, three reversals, SSG/CSR tables, Schema-as-annotation, FO 5-step, CRO frameworks, “pages are not the unit” as a slogan. Blind-spot checklist only. No tweet id → do not add.

## Source priority

Long-form writing **by him** > **decision / refusal replies** > thanks-only / empty RTs. Conversation-partner tweets are not doctrine.
